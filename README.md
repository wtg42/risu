# Risu

Risu is a native Zig library for beautiful, lightweight, and composable
interactive CLI prompts.

The project is inspired by [Clack](https://github.com/bombshell-dev/clack) and
is currently at the initial project-scaffolding stage. Its prompt API has not
yet been designed.

## Requirements

- Zig 0.16.0

## Test

```sh
zig build test
```
